RTOS-Based Smart Environmental Monitoring System

Project overview

An academic project exploring how an RTOS can organize environmental sensor monitoring into separate tasks. The planned system uses an ESP32-class board, sensors, and a display or dashboard to present readings.

Challenges & learning

Designing task priorities and timing, sharing sensor data safely between tasks, and avoiding blocking operations are important challenges to investigate and report from the actual build.

Future improvements

Measure task timing and response latency, add robust error handling, log sensor data, and evaluate jitter under different workloads.
